1. How the Robot "Sees" and Avoids Obstacles

The G1 robot uses a 3D LiDAR sensor (Livox MID-360) that emits laser beams 360° around the robot and measures the distance to every surface it hits — like a flashlight that can measure distance. The system processes this data 10 times per second through a multi-stage pipeline shown below.

2. Key Technologies at a Glance

🗺️ Nav2 Local Costmap

A 4m × 4m "danger map" that moves with the robot. Each 5 cm cell stores a cost value (0 = safe, 254 = obstacle). Obstacles are inflated — like drawing a safety bubble around every wall — so the robot keeps its distance automatically.

🧭 DWA Planner

Dynamic Window Approach: generates 100 candidate paths per cycle, each a smooth curve the robot could physically follow. Every path is scored for safety, goal progress, and smoothness. The highest-scoring path is executed.

🔄 Stuck Recovery

If the robot detects no position change for 5 seconds despite sending commands, it enters a 3-phase escape: reverse → rotate toward clearest direction → advance. Clearance direction is chosen by sampling the costmap in 8 sectors around the robot.

3. The Costmap "Safety Bubble" — How the Robot Keeps Distance

The costmap wraps every detected obstacle in a graduated inflation zone. The robot treats areas with higher cost as more dangerous and naturally steers toward lower-cost (safer) zones. This is the same industry-standard technique used by the ROS 2 Navigation Stack (Nav2).

Figure 2 — Costmap inflation cross-section: cost decreases exponentially from obstacle surface. Robot prefers zero-cost areas.

4. Corridor Navigation — The Hardest Scenario

In a 1.0 m wide corridor, the G1 robot (width 0.55 m) has only 22.5 cm clearance per side. The system uses three coordinated mechanisms to traverse safely:

Figure 3 — Corridor cross-section: inflation from both walls creates a safe central channel that guides the robot

Three Coordinated Safety Mechanisms

# Mechanism What It Does Corridor Behaviour
1 A* Global Path Plans the shortest collision-free route on the static map, automatically routing through corridor center. Provides a centerline reference. Robot follows this line when no dynamic obstacle is present.
2 Costmap Gradient Inflates every wall with an exponential cost field. DWA trajectory scoring penalizes paths entering high-cost zones. Creates a "magnetic center" effect — if robot drifts sideways, the cost gradient gently pushes it back to center.
3 Narrow-Cone Detection Scans only ±30° ahead (not ±90°) and requires ≥ 8 high-cost samples to trigger DWA avoidance mode. Side walls are not detected as obstacles → robot stays in smooth A* tracking mode. Only a person or box directly ahead triggers active avoidance.

6. System Behaviour Summary

✅ Open Area

A* path → straight-line to goal. No DWA activation. Full speed (0.20 m/s).

✅ Narrow Corridor

A* path through center. Costmap gradient centers the robot. DWA stays off. Steady forward motion.

⚠️ Obstacle Ahead

DWA activates. 100 paths scored. Best path curves around obstacle while staying away from walls.

🛑 Robot Stuck

Escape mode: reverse → rotate to clearest direction → advance. Auto-resumes normal navigation.
