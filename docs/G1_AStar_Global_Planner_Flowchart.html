A* (A-Star) Global Planner — Flowchart & Logical Procedure

Reference implementation: navigation_controller/scripts/astar_planner_ros2.py · ROS 2 Humble
Role: compute a collision-free sequence of waypoints on an occupancy grid from current pose to goal, then publish /astar_path for the local planner and controller.

Problem statement. Given a 2D grid map where each cell is free or occupied, a start cell s and a goal cell g, find a minimum-cost path from s to g moving only through free cells. A* is a best-first search that uses an admissible or informed heuristic to expand fewer nodes than Dijkstra’s algorithm while still guaranteeing optimality when the heuristic is admissible and costs are consistent.

1. Conceptual formula (why A* is “logical”)

For each grid cell n:

  • g(n) — actual cost from start → n along the best path found so far (cumulative step costs).
  • h(n) — heuristic estimate of cost from n → goal (must be fast to compute; in this project: Euclidean distance, optionally augmented with a turn penalty).
  • f(n) = g(n) + h(n) — priority score; the algorithm always expands the node in the open set with the smallest f first.

Implementation detail: The code stores g_score and f_score dictionaries keyed by (x, y) map indices, and uses Python’s heapq as a min-heap on f for the open list.

4. Step-by-step logical procedure

0

Precondition — grid model

Convert the continuous world into a discrete grid: each cell has an occupancy value. Cells with value ≥ 50 are treated as obstacles. The inflated map widens no-go regions so the planned path keeps a safety margin from physical walls (robot radius + inflation radius in meters, converted to pixels).

1

Define start and goal cells

Map frame positions from /odometry/map (start) and /move_base_simple/goal (goal) are converted to integer indices (start_x, start_y), (goal_x, goal_y) via world_to_map(). If either lies on an obstacle or outside the map, planning aborts early with diagnostics.

2

Initialize search state

g_score[(sx,sy)] = 0, f_score[(sx,sy)] = h(sx,sy), push (f, sx, sy) onto open_set (min-heap). closed_set = ∅, came_from = {}.

3

Main loop — pop best frontier node

While open_set is non-empty, pop the cell with minimum f. This is the “most promising” unexplored frontier because it minimizes estimated total cost f = g + h.

4

Goal test

If the popped cell equals (goal_x, goal_y), reconstruct the path by following came_from pointers from goal back to start, reverse the list, then apply smoothing — done.

5

Close current cell

Add current to closed_set. Any path through a closed cell will not be reconsidered (standard A* with consistent heuristic).

6

Expand neighbors

For each valid neighbor from get_neighbors() (8 directions, step cost 1 or √2 in grid units): if neighbor is already closed, skip. Compute tentative_g = g(current) + edge_cost. If this improves the best known g(neighbor), record came_from[neighbor] = current, update g_score and f_score = g + h(neighbor), and push to the heap.

7

Termination — failure

If open_set empties without reaching the goal, no connected free path exists under the current inflation map (blocked corridor, goal inside wall, or excessive inflation).

8

Post-processing

Raw A* paths are jagged on an 8-connected grid. smooth_path_for_g1() reduces unnecessary zig-zags and adjusts point spacing for humanoid stepping; waypoints are converted back to world coordinates and published as nav_msgs/Path on /astar_path.

5. Design choices in this project (professional notes)

TopicChoiceRationale
Open set structure heapq (binary min-heap) O(log N) insert/extract; each cell may be pushed multiple times when a better g is found — correct and common in practice.
Neighbor connectivity 8-connected grid Allows shorter paths than 4-connected; diagonal cost √2 preserves Euclidean interpretation of step length.
Heuristic Euclidean distance + optional turn penalty Biases search toward goals that are easier for a humanoid to approach; not strictly admissible if penalty is large — trade-off for motion feasibility.
Inflation Distance transform (SciPy) Same mathematical idea as Nav2 costmap inflation: approximate “keep away from obstacles” before graph search.
