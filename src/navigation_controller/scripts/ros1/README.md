# ROS1 Legacy Scripts

This directory contains ROS1-only historical implementations.

## Why it is kept
- Reference for migration decisions.
- Field troubleshooting when comparing ROS1 and ROS2 behavior.

## Important
- These scripts are **not** part of the ROS2 runtime chain.
- Do not launch them in ROS2 environments.
- Active ROS2 runtime scripts are located under:
  - `src/navigation_controller/scripts/`

## Maintenance policy
- Keep as read-only legacy reference unless a dedicated migration task is requested.
